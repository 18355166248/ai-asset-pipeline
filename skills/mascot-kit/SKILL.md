# 吉祥物素材包

此 Skill 与 `ai-asset-pipeline` 一起使用。先解析当前 SKILL.md 的真实路径（安装目录可能是软链），向上两级得到仓库根目录。命令使用该根目录的绝对路径，不依赖用户当前项目的 cwd。工具说明见 [素材工具箱](../../docs/TOOLKIT.md)。

## 从需求到素材

- 先读目标项目的名称、用途、现有配色和用户给定参考。已有明确主题时直接沿用；仅缺少会影响结果的信息时询问。
- 开放需求默认提出三个简短方向，说明轮廓、主色与性格；数量、题材和构图服从用户选择。用户已指定方向或要求直接出图时直接执行，不重复确认。
- 候选保持简单大轮廓、少量主色，小尺寸能看清五官。先固定主体与风格，再改变表情或构图，不把所有维度同时重抽。
- 原图生成和编辑使用宿主提供的图片生成工具，遵循其工具说明；若提供了 imagegen Skill，读取后使用。工具不可用时交付提示词与加工配方，并说明尚未生成，不用程序画图冒充 AI 候选。
- 默认一轮三个候选；用户指定数量时按其要求。保留每个候选原图，不进行无限自动重试。保留完整提示词、参考图位置与来源；没有可核对用量时记录 unknown。
- Logo 或头像允许保留纯色背景。仅用户需要独立透明素材且背景适合色键时使用 chroma，不把设计背景误删。

## 导出与交付

复制 [静态配方](../../recipes/mascot.json) 到本次工作目录，填写 title、source、sizes。source 记录原图来源、提示词与参考图路径；默认尺寸为 32、64、128、256 px。工具不会生成 ICO、矢量 SVG 或完整平台 App Icon 包，不将 PNG 尺寸包描述成这些格式。

```bash
python3 <pipeline-root>/src/asset_bundle.py \
  --recipe <本次配方.json> --input <候选图片目录或单图> --out <新的素材包目录>
```

使用已安装 Pillow 与 NumPy 的 Python 3.10+ 解释器；优先检查仓库已有的 `.venv-cutout/bin/python` 或 `.venv-toolkit/bin/python`，用可用者替换命令中的 python3。必要时按工具箱文档建独立虚拟环境，不改写系统 Python。

打开 preview.html，以 1× 查看 32/64 px，再检查深浅背景。比较候选的轮廓、五官和透明边缘；自动报告不能代替审美检查。交付预览页、PNG 尺寸包与 manifest.json，解释哪些是已验证的文件行为，哪些仍需用户选稿或目标产品验证。生成的新资产按目标项目约定入库；加工输出默认是草稿，不自动覆盖正式资源。
