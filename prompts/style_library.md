# 画风词菜单

挑**一条**贴进模板的 `{{STYLE}}`，然后整个项目锁死它别混。每条都已针对
「游戏图标 + 好去背」调过（浅平背景、清晰轮廓、统一光照）。

---

### 1. 扁平矢量图标（最百搭，休闲小游戏首选）
```
Cute flat-vector game icon, soft rounded shapes, thick uniform outline,
2-3 flat color tones per item with simple cel shading, clean and playful
mobile-game look, soft top-left lighting.
```

### 2. 卡通 3D / 黏土渲染（Q 弹立体，合成类合适）
```
Cute 3D cartoon render, soft clay-like material, rounded chunky shapes, glossy
but not reflective, gentle studio lighting, isometric 3/4 view, playful mobile
game asset look, clean solid background.
```

### 3. 手绘描边卡通（暖、有手作感）
```
Hand-drawn cartoon style, slightly wobbly ink outline, warm gouache-like flat
coloring, subtle paper texture only on the item (not the background), cozy
storybook game look, even soft lighting.
```

### 4. 像素风（复古、包体小）
```
Clean pixel-art game sprite, limited cohesive palette, crisp pixels, subtle
dithering for shading, consistent light from top-left, retro 16-bit look,
no anti-aliased edges.
```

### 5. 描边 icon / 极简线性（UI、道具槽合适）
```
Minimal line-icon style, uniform 2px rounded stroke, single accent fill color,
flat and geometric, modern clean UI look, no gradient.
```

### 6. 拟真图标（写实但干净，美食/道具）
```
Semi-realistic glossy game icon, soft rendered volume, rich but clean colors,
smooth gradients inside the item only, studio product lighting, 3/4 view,
polished casual-game look.
```

---

## 用法要点

- **只选一条**，整套 36 格用同一条；补图时也用同一条 + 参考图。
- 想微调，只改**颜色/光照措辞**，别换整条画风词。
- 背景色统一写在模板的 `{{BG}}`，画风词里已声明「clean/solid background」呼应它。
- 不确定选哪条 → 先用 **1 号扁平矢量** 出一版试水，它最稳、最好去背。
