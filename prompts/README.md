# Prompt 库 · 6×6 同风格素材网格

给**网页版 GPT / Gemini** 手工粘贴用的成熟提示词。复制模板 → 填空 → 出图 → 存到
`../input/`，再跑本地管线切图去背。

## 文件

| 文件 | 用途 |
|---|---|
| `item_grid.md` | ⭐ 主模板：一次出 36 个同风格 item |
| `character_forms.md` | 同一角色的 36 种形态 / 状态 |
| `add_item.md` | 补图：给已有套系再加 N 个，保持一致 |
| `style_library.md` | 画风词菜单（挑一个锁死，别混） |

也可以用脚本自动填好：
```bash
python ../src/gen_prompt.py --style "flat vector game icon" --bg "#F2EFE9" \
  --items "苹果,香蕉,西瓜,葡萄, ...(36个)"
```

## GPT vs Gemini：什么时候用哪个

| 场景 | 推荐 | 原因 |
|---|---|---|
| 首次出整套 36 格 | **两个都试** | 各生一版对比一致性，选稳的那个当主力 |
| 结构化排版（严格 6×6、按列表逐格） | **GPT** | 更听「网格 + 编号列表」这类结构指令 |
| 补图 / 保持角色一致（传参考图再改） | **Gemini** | 参考图一致性、局部编辑更强 |

## 铁律（每个模板都已内置，这里是原因）

1. **单一纯平背景色**：写死一个 flat 色（如 `#F2EFE9`），**禁止渐变、禁止投影** → 去背才干净。
2. **每格一个物件、居中、同比例**（约占格 70%）→ 切图 + autocrop 才准。
3. **锁死一种画风**：同描边粗细、同上色方式、同视角、同光照、同配色。
4. **禁止**：文字 / 数字 / 标签 / 网格线 / 边框 / 水印 / 投影。
5. **正方形 1:1 画布**。

## 出图后

存 `../input/xxx.png`，然后：
```bash
python ../src/run.py input/xxx.png -r 6 -c 6 --size 96 --autocrop
```
打开 `output/xxx/contact_cutouts.png` 判定一致性 & 去背质量。
