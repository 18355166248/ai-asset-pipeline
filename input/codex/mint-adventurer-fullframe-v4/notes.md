# v4 完整角色原画：待用户方向验收，未通过正式动作验收

2026-10-02。基于 v3 的十二相位姿势草图与原角色参考，实际调用 Codex 内置 imagegen 两次：完整角色逐帧重绘、仅修正远侧腿蓝灰皮肤。`walk-draft.png` 保存带错误颜色的候选，`walk.png` 保存清理候选。没有调用 Grok / Scenario / sprite-gen，也没有生成连续视频。

优点：整个角色连贯绘制，消除了硬切膝盖、手肘接缝。问题：身体/服饰轮廓仍有变化，近远腿身份与循环步态未能可靠确认，末帧到首帧也需要人工看连续播放。因此 **pending-review-with-known-issues**，不是正式可用动作。

实际源图 1254×1254 RGBA，未达到提示词请求的 1536×1536。角色行距不均；简单 4×3 等分会读入相邻行的靴子。`frame-layout.json` 显式记录三个行裁框与每帧脚底锚点。每帧仅作平移配准，不按 bbox 缩放、不改帧顺序、不横向对齐，不插帧。脚底锚点取已核对的最低不透明靴子像素，前提是步行每帧至少一只脚落地；此方法不应无条件用于跳跃、奔跑或不同相机画面。

12 帧 / 800ms 是本次试播参数，不是帖子视频的实测帧率。原画 66/67ms 的累计取整确保总长恰好 800ms。WebP 保留时长；GIF 受 10ms 精度限制，用累计取整分配 60/70ms，仍为 800ms。源帧没有混合淡入或复制为更多帧。
